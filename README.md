This project focuses on clean layout structure, responsive design, and modern CSS techniques to create a simple yet professional web presence.

## Tech Stack

- HTML5
- CSS3
- CSS Grid
- Flexbox

- Responsive layout
- Smooth scrolling navigation
- Project showcase section
- Skills section
- Contact section
